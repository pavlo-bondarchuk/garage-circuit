# Garage Circuit

Браузерная low-poly аркадная игра с гаражом, покупкой и тюнингом автомобилей.

## Возможности

- 12 автомобилей: седаны, купе, хэтчбек, внедорожники, пикап и грузовик.
- Бесплатный Peugeot 301 и 10 000 $ на старте.
- Цены от 23 000 $ до 3 млрд $, предел баланса — 50 млрд $.
- Покраска, двигатель, турбо, шины и антикрыло.
- Открытый мир, кольцевая гонка, ралли, драг на 402 м и краш-арена.
- Стартовый экран, сенсорное управление несколькими пальцами, отдельные кнопки передач.
- Прогресс сохраняется в localStorage этого браузера.

## Запуск

Требуется Python 3 либо любой HTTP-сервер для статических файлов.

```sh
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Запуск через file:// не поддерживается ES-модулями.

## Управление

| Действие | Управление |
| --- | --- |
| Газ / тормоз / руль | WASD или стрелки; сенсорные кнопки |
| Ручник | Пробел или кнопка |
| Повысить передачу в драге | Shift или + |
| Понизить передачу в драге | Ctrl или − |
| Вернуть машину на маршрут | R |
| Осмотр машины в гараже | Перетаскивание; колесо для масштаба |

## Структура

- `dist/index.html` — игровой интерфейс.
- `dist/style.css` — стили и адаптация к сенсорным экранам.
- `dist/game.js` — сцена, модели, управление, экономика и режимы.
- `dist/three.module.js`, `dist/three.core.js` — Three.js 0.180.0.
- `dist/THREE-LICENSE.txt` — лицензия Three.js.

Приложение статическое, сборка и API-ключи не нужны. Для хостинга укажите папку `dist`. Шрифты загружаются через Google Fonts; предусмотрены системные альтернативы.
